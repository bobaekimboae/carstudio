# Car Studio 한국어 영상 제작기

Car Studio의 사진 업로드와 차량 상세 입력 흐름을 참고해 새로 작성한 한국어 차량 소개 영상 제작기입니다. 9:16, 1:1, 16:9 형식의 사진 영상을 브라우저에서 만들고 미리보기·다운로드할 수 있습니다.

## 실행

정적 사이트라 별도 패키지 설치가 필요하지 않습니다.

```sh
node server.cjs
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. GitHub Pages에 올릴 때는 저장소 루트의 `index.html`, `styles.css`, `app.js`를 그대로 게시하면 됩니다.

## 사용 방법

1. JPG, PNG 또는 WEBP 사진 8~15장을 올립니다.
2. 한국어를 비롯한 영상 언어를 선택하고 차량 정보로 이동합니다.
3. 제조사·모델·연식·가격을 입력하고 선택적으로 주행거리, 연료, 변속기, 판매자 연락처를 추가합니다.
4. 템플릿, 색상, 영상 비율, 배경 음악, 한국어 AI 음성 해설과 화면 자막을 선택합니다.
5. 영상 만들기를 눌러 렌더링하고 미리보기 또는 다운로드를 선택합니다.

사진은 브라우저 메모리에서 처리됩니다. 영상은 브라우저의 Canvas와 MediaRecorder로 제작되고, 템플릿·색상 팔레트·비율·음악·자막 설정이 결과에 반영됩니다. 지원되는 인코더가 있으면 MP4, 그렇지 않으면 WebM으로 저장합니다. 차량 정보와 한국어 음성 원고는 사용자가 확인·입력한 값으로 구성하며, 자동 차량 인식은 제공하지 않습니다.

### 한국어 AI 음성

Node 로컬 서버는 `POST /api/tts`에서 OpenAI Speech API를 호출해 차량 정보에 맞춘 한국어 원고를 MP3로 반환하고, 영상에 배경 음악과 함께 넣습니다. 기본 목소리는 `marin`이며 부드럽고 차분한 진행 톤을 지정했습니다. OpenAI의 목소리는 원본 Car Studio 음성과 동일하거나 복제된 것이 아닙니다. 한국어는 지원하지만 목소리는 영어에 최적화되어 있습니다. API 키는 `OPENAI_API_KEY` 환경 변수에만 넣어야 합니다. 키를 `config.js`, HTML, 공개 GitHub 저장소에 넣지 마세요. 음성 설정은 추가 API 비용이 발생할 수 있습니다. 서버의 `OPENAI_TTS_VOICE`와 `OPENAI_TTS_MODEL` 환경 변수로 음성·모델을 설정할 수 있습니다. 기본 모델은 2027년 1월 6일 지원 종료 예정이므로, 그 전에 후속 모델로 전환해야 합니다.

GitHub Pages는 백엔드와 비밀 키를 보관할 수 없으므로 배포 화면에서는 AI 음성 토글이 비활성 상태입니다. 실제 배포에서 사용하려면 HTTPS가 적용된 별도 서버를 운영하고, `config.js`의 `ttsEndpoint`를 해당 서버의 `/api/tts` HTTPS 주소로 설정해야 합니다. 서버의 `CARSTUDIO_ALLOWED_ORIGINS`에는 `https://bobaekimboae.github.io`를 포함하세요. 기본 요청 제한도 적용되어 있습니다.

## 배포

GitHub Pages에서 `main` 브랜치의 `/ (root)`를 게시하면 됩니다. 커스텀 도메인 없이 저장소 주소가 `bobaekimboae/carstudio`일 경우 접속 주소는 `https://bobaekimboae.github.io/carstudio/`입니다.
